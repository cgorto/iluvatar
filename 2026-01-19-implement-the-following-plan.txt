  # QUIC Networking Implementation Plan                                         
                                                                                
  ## Overview                                                                   
                                                                                
  Implement QUIC transport between camera units and the server using quinn      
  0.11 (already a dependency). This completes the data pipeline that's          
  currently stubbed.                                                            
                                                                                
  ## Design Decisions                                                           
                                                                                
  1. **TLS certificates**: Generate self-signed at runtime if not               
  configured, persist to `~/.iluvatar/certs/`                                   
  2. **Stream design**: Single bidirectional stream for registration            
  (request/response), unidirectional streams for frame data                     
  (fire-and-forget)                                                             
  3. **Framing**: 4-byte length prefix (u32 BE) + postcard-serialized           
  message                                                                       
  4. **Server architecture**: One spawned task per camera connection            
  (matches WebSocket pattern)                                                   
  5. **Reconnection**: Exponential backoff (100ms → 30s) with jitter
